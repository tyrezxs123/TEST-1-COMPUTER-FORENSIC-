WEEK 7Digital forensics tools

Week 7 covers 7 tools (or tool groups). Each one is good at a different kind of evidence. The key is to know what evidence each tool looks at.

1. FTK Imager

What: A free tool by AccessData for imaging (making an exact copy of) and looking at storage devices: hard drives, SSDs and network shares.

Features (from slide): supports many file systems, image carving, hash matching, report generation.

Side note: the slide calls FTK Imager "free and open-source". It is free, but its code is not open-source (it is owned by AccessData, now Exterro). In the test, write "free tool by AccessData" and you're safe either way.

5. ProDiscover

What: Software to analyse and extract evidence from computers, smartphones and other storage. The lab uses ProDiscover Free Edition with a DD file (raw image) called RHINOUSB.7z.

Two views:

WEEK 7File systems & the boot sequence

File system

A file system gives the operating system (OS) a road map to the data on a disk. The type of file system (e.g. NTFS, FAT32, ext4) decides how data is stored. An investigator must know both the OS and the file system before acquiring or inspecting a suspect's computer.

AnalogyThe disk is a huge library. The file system is the library catalogue that says "Book X is on shelf 5, row 3". Different libraries use different catalogue systems, so you must know which one you are reading.

Boot sequence

  • CMOS (Complementary Metal Oxide Semiconductor): stores system configuration and date/time, even when power is off (kept alive by a small battery).
  • BIOS (Basic Input/Output System) or EFI (Extensible Firmware Interface): programs that do input/output at the hardware level.
  • Bootstrap process: stored in ROM; tells the computer how to start. It shows which key opens the CMOS setup screen (e.g. F2, Del).
  • Master Boot Record (MBR): stores information about the partitions on a disk.
Exam tip: why does boot matter in forensics? If you just switch on a suspect's computer, Windows starts and changes files (timestamps, logs). So the investigator changes the CMOS/BIOS boot order to boot from a forensic boot CD or USB instead. This lets you access the disk without altering evidence. Also check the CMOS clock: it may be wrong, which affects your timeline.
Memory trick"C-B-B-M": "Cik Bawa Buku Merah" → CMOS → BIOS/EFI → Bootstrap → MBR

WEEK 7Disk drives & partitions

A hard disk is made of one or more platters (round plates) coated with magnetic material.

AnalogyA platter is like a vinyl record / CD. A track is one lane of a running track. A sector is a slice of pizza cut from that lane. A cylinder is the same lane on every floor of a multi-storey car park. The head is the record player's needle.
Memory trick: disk components"Good Heads Track Cute Sheep" → Geometry · Head · Tracks · Cylinders · Sectors

Properties handled by the drive's hardware/firmware

  • Zone Bit Recording (ZBR): outer tracks are longer, so they hold more sectors than inner tracks. Uses space better.
  • Track density: how close together the tracks are (space between tracks).
  • Areal density: number of bits in one square inch of the platter.
  • Head and cylinder skew: shifts the starting sector between tracks/heads so the head doesn't miss the next sector while it moves. Makes reading faster.
Memory trick"Zebra Talks About Shoes" → ZBR · Track density · Areal density · Skew

Disk partitions

Disk partitioning = dividing one hard drive into several logical storage units called partitions (e.g. C: and D:).

Why partition?

  • Organization: keep OS, programs and data separate.
  • Multiple operating systems: e.g. Windows on one, Linux on another (dual boot).
  • Performance: smaller partitions can be faster to manage.
  • Data backup and recovery: if the OS partition breaks, the data partition survives.
Memory trick"Old Men Play Badminton" → Organization · Multiple OS · Performance · Backup & recovery
AnalogyA disk is a house; partitions are rooms. Same house, but the kitchen and bedroom have different uses. Unallocated space is the empty land not yet built into a room.

Practical tip (slide): press Windows + R, type diskmgmt.msc to open Disk Management. Right-click unallocated/free space to create a partition.

Exam tip: forensic angleSuspects can hide data in hidden partitions or in gaps between partitions. Always check the full disk, including unallocated space, not just the visible drives.

WEEK 7BitLocker & disk encryption

Microsoft BitLocker is a full volume encryption feature built into Windows. It protects data by encrypting whole drives. Without the password or recovery key, the data looks like random garbage.

Third-party Whole Disk Encryption (WDE) tools:

  • PGP Full Disk Encryption
  • Voltage SecureFile
  • Utimaco SafeGuard Easy
  • Jetico BestCrypt Volume Encryption
  • TrueCrypt
Memory trick: 5 WDE tools"Please Visit Uncle Jack Today" → PGP · Voltage · Utimaco · Jetico · TrueCrypt
AnalogyEncryption is like putting the whole house inside a giant safe. Even if police take the house (seize the disk), they can't see inside without the key (password / recovery key).
Exam tip: why is encryption a challenge? If you shut down an encrypted computer, the data locks again. So investigators may need to (1) capture RAM first (the key may be in memory → Volatility), (2) look for the recovery key (e.g. printed, saved to a Microsoft account or USB), or (3) image the drive while it is still unlocked.

WEEK 7Virtual machines

A virtual machine (VM) lets you create a computer inside your computer, running as a Guest OS on top of the physical (host) machine.

  • A VM is just a few files on your hard drive.
  • You must allocate space (disk, RAM) to it.
  • It recognises the components of the physical machine it runs on.
  • The virtual OS is limited by the physical machine's OS and hardware.

In digital forensics, VMs let you:

  • Restore a suspect's drive inside a VM and see it "as the suspect saw it".
  • Run nonstandard software the suspect may have installed, without risking your own machine.

Network forensics issue: a suspect may use a VM to attack another system or network, then delete the VM files to hide the attack. So investigators must look for VM files on suspect drives.

Popular VM software: VMware Server, VMware Player, VMware Workstation, Oracle VM VirtualBox (open-source, free), Microsoft Virtual PC, Hyper-V.

AnalogyA VM is a "house within a house", like a playhouse/sandbox inside your living room. Whatever mess happens inside the sandbox doesn't dirty the real house. Delete the sandbox, and it is gone.

WEEK 8Recognising graphics files

Graphics files hold digital photos, line art, 3D images and scanned copies of printed pictures. There are 3 types:

Bitmap and raster images

  • Bitmap: a grid of individual pixels. Raster: also a collection of pixels, stored in rows.
  • Better for printing (raster).
  • Image quality depends on: (1) screen resolution (amount of detail), (2) software/drivers, (3) number of colour bits per pixel (colour depth).
FeatureBitmapRaster
DefinitionEach pixel maps directly to bits; originally 1-bit (black/white only)Broader term: any image made of a grid of pixels, many colour depths
Colour depthOriginally 1-bit (monochrome); now also colour1, 8, 24, 32-bit etc.
File formats.bmp, .dib.bmp, .jpg, .png, .gif, .tiff…
UsageOlder term, often uncompressedGeneral term (photos, web)
ScalabilityLoses quality when enlarged (pixelation)Same: resolution-dependent
CompressionUsually uncompressed → big filesCan be lossy (JPEG) or lossless (PNG)
Key sentence to memorise"All bitmaps are raster images, but not all raster images are bitmaps." Like: all durians are fruit, but not all fruit are durians.

Vector graphics

  • Use lines instead of dots.
  • Store only the calculations (math) for drawing lines and shapes.
  • Smaller than bitmap files.
  • Keep quality when enlarged.
  • Programs: CorelDraw, Adobe Illustrator.

Metafile graphics

A combination of bitmap and vector in one file. Example: a vector drawing with a pasted photo inside it. When you enlarge it, the vector part stays sharp but the bitmap part becomes blocky. (Formats like .wmf / .emf.)

Analogy Bitmap = a mosaic / cross-stitch: thousands of small tiles. Stand too close (zoom in) and you see the squares.
Vector = a recipe: "draw a circle of radius 5 cm". You can cook it for 2 people or 200 and it's still perfect.
Metafile = a scrapbook: hand-drawn lines (vector) with photos glued on (bitmap).
Memory trick: 3 types"B-V-M: Bitmap = dots, Vector = math, Metafile = mix" (M for Mix, M for Metafile)

Programs

  • Graphics editors: create and change images (e.g. Photoshop, Paint, GIMP).
  • Image viewers: only display images (e.g. IrfanView, Windows Photos).

WEEK 8Digital camera file formats: RAW & Exif

Witnesses or suspects can take their own digital photos, so investigators must understand camera formats.

RAW format

  • Called a "digital negative".
  • Found on higher-end digital cameras.
  • The camera sensor simply records pixels straight onto the memory card (no processing).
  • Keeps the best picture quality.
  • Biggest disadvantage: it is proprietary (each camera brand has its own format), and not all viewers can display it.
  • Converting raw data into another format (e.g. JPEG) = demosaicing.
AnalogyRAW is like uncooked ingredients: best quality, but you need the right kitchen (software) to cook it. Demosaicing is the cooking: turning raw sensor data into a finished picture. The word comes from "mosaic", because the sensor captures colour in a mosaic pattern of red/green/blue dots.

Exif (Exchangeable Image File) format

  • Commonly used to store digital pictures.
  • Developed by JEITA (Japan Electronics and Information Technology Industries Association) as a standard for storing metadata in JPEG and TIF files.
  • Metadata tells you the type of camera and the environment where the photo was taken.
  • Exif stores metadata at the beginning of the file.
  • Need special programs to view: Exif Reader, IrfanView, ProDiscover.
  • With these tools you can extract metadata as evidence.

Typical Exif evidence: camera make & model, date and time taken, GPS location, shutter speed, aperture, flash, resolution, software used to edit.

AnalogyExif metadata is the label on a food package: who made it, when, where, ingredients. The photo is the food; the Exif is the label stuck on the front.
Memory trick"Exif = EXtra InFo" (extra information about the photo). Developed by JEITA = Japan (think of Japanese camera brands: Canon, Nikon, Sony).
Exam tipA typical question: "How can Exif metadata help an investigation?" Answer: it can prove which camera took the photo (link to suspect's camera), when it was taken (check alibi), and where (GPS). Remember metadata can be edited, so confirm it with other evidence.

WEEK 8Damaged headers, carving & rebuilding

What is a file header?

Every graphics file starts with a unique header value (also called a magic number or file signature). It tells the computer "I am a JPEG" no matter what the file extension says.

offset 6 Offset = position counted from 0. (An Exif JPEG has FF D8 FF E1 and the label "Exif" at offset 6.)
  • JPEG header: FF D8 FF E0 00 10
  • Most JPEG files also include the string JFIF (JPEG File Interchange Format).
  • A JPEG starts with FFD8, followed by the label JFIF (standard JPEG) or Exif at offset 6.
Memory trick"FF D8 = Fast Food Delivery 8 o'clock". Every JPEG "orders food" first. Then at seat number 6 sits JFIF ("Just Fine Image File").
AnalogyThe header is the name tag on a parcel. If someone scratches off the tag (damaged header) or puts a fake label (wrong extension, e.g. holiday.txt), the parcel looks unknown, but the contents inside are still the photo. Fix the tag and it opens again.

Lab exercise: investigate possible intellectual property theft by a contract employee of Exotic Mountain Tour Service (EMTS), where photos had damaged headers that needed repair.

Searching for and carving data from unallocated space

Unallocated space = disk area marked as "free". When a file is deleted, its data often stays there until overwritten. Carving = finding and cutting out file pieces from that space using their header (and footer) signatures, without relying on the file system.

Steps (slide):

  1. Planning your examination: what are you looking for, which tool, which file type.
  2. Searching for and recovering digital photo evidence: use ProDiscover to search for and extract possible JPEG evidence.

False positives = false hits: the search finds the pattern (e.g. "FFD8" or "JFIF"), but it is not really an image file (e.g. those bytes just happen to appear inside another file). Each hit must be checked.

AnalogyCarving is like looking through a rubbish dump for torn photographs. You search for the corner with a photo-studio logo (the header) and cut out what follows. Sometimes you find a logo on a cereal box: that's a false positive.

Rebuilding file headers

Before editing a recovered file, first try to open it with an image viewer. If it does not display, inspect and fix the header manually in a hex editor.

  1. Recover more pieces of the file if needed.
  2. Examine the file header.
  3. Compare it with a good header sample (a known-good JPEG).
  4. Manually insert the correct hexadecimal values (e.g. type FF D8 FF E0 00 10 4A 46 49 46).
  5. Test the corrected file (open it in a viewer).
Memory trick: 5 steps"Really Every Cat Is Tiny" → Recover · Examine · Compare · Insert · Test
Exam tip: always mention hashing & documentationWhen you rebuild a header you change the file. So work on a copy, record the hash before and after, and document every byte you changed so the evidence is still acceptable in court.

Tools for viewing images

  • After recovering a graphics file, open it with an image viewer.
  • No single viewer can read every format, so having many viewers is best.
  • Most GUI forensic tools (Autopsy, FTK, ProDiscover) include built-in viewers for common formats.
  • Analyse, identify and inspect every unknown file on a drive.

WEEK 8Steganography & steganalysis

Steganography = hiding information inside another file (like an image) so nobody knows a secret is there. It is an ancient technique (the Greek word means "covered writing").

AnalogyEncryption = a locked box: everyone can see the box, but can't open it.
Steganography = a secret drawer inside a normal cupboard: nobody even knows there's something to open.

Two major forms

1. Insertion
  • Adds hidden data into the file.
  • Hidden data is not displayed when the host file is opened in its normal program.
  • You must analyse the data structure carefully to find it.
  • Example: a web page: text hidden in the HTML code (e.g. comments, white text on white) doesn't show in the browser but is in the source.
  • Effect: file size grows.
2. Substitution
  • Replaces bits of the host file with bits of secret data.
  • Usually changes the last two LSBs (least significant bits) of each byte.
  • The change is too small for the human eye to see.
  • Detected with steganalysis tools (steg tools).
  • Effect: file size stays the same.

How LSB substitution works (picture)

Analogy for LSBIf you have RM203.00 and someone changes it to RM201.00, you'd notice. But if they change RM203.00 to RM203.01, nobody notices. The LSB is the "1 sen" digit of each pixel.
Memory trick: Insertion vs Substitution "Insertion INcreases, Substitution Swaps"
Insertion = Insert extra data → size goes up, hidden in structure.
Substitution = Swap the last bits → Same size, needs Steg tools.

Clues of steganography (what to look for)

  • Duplicate files with different hash values: two pictures look identical, but hashes differ → one may carry hidden data.
  • Steganography programs installed on the suspect's drive.
  • Changes in file size, image quality or file extension.
Memory trick: clues"Twins With Different Fingerprints": two identical-looking files (twins) with different hashes (fingerprints) = suspect steganography.

Steganalysis tools

  • Steganalysis = finding out whether a file hides information.
  • Steg tools are used to detect, decode and record hidden data.
  • They detect variations of the graphic image (compare with the original if available).
  • If steganography is applied correctly, in most cases you cannot detect the hidden data.
  • Check whether file size, image quality or file extension have changed.

You should inspect all files for evidence of steganography.

Exam tip"Detect, decode, record" are the 3 jobs of steg tools: "D-D-R: Doctor Diagnoses, Records".

WEEK 8Copyright issues with graphics

  • Steganography is also used for a good purpose: to protect copyrighted material by inserting digital watermarks into a file.
  • Digital investigators need to be aware of copyright laws.
  • Copyright laws for the Internet are not clear.
  • There is no international copyright law; each country has its own.
  • Check www.copyright.gov: the U.S. Copyright Office lists what can and can't be covered under U.S. copyright law.
AnalogyA digital watermark is like the hidden security thread in a Ringgit note: you don't normally see it, but it proves the note is genuine and who issued it. A photographer hides a watermark in a photo to prove "this is mine".
Link to the EMTS caseThe EMTS exercise (intellectual property theft by a contractor) connects to copyright: recovered photos + watermark/metadata can prove the images belong to EMTS.

Part A: Week 7 (Tools, Windows, File systems)

Q1. What is FTK Imager? State THREE of its features. [4 marks]

FTK Imager is a free digital forensics tool developed by AccessData. It lets investigators create forensic images (exact copies) of storage devices such as hard drives, SSDs and network shares, and analyse them without changing the original.

Features (any three):

  1. Supports a wide range of file systems.
  2. Image carving: recovers files from the image.
  3. Hash matching: proves the copy is identical to the original.
  4. Report generation.
Q2. Explain FIVE key features of the Autopsy forensic tool. [5–10 marks]
  1. File system analysis: lets the investigator navigate the device's file system to find and analyse files.
  2. Data extraction: extracts images, videos, documents and other artifacts.
  3. Data recovery: recovers deleted or corrupted files.
  4. Timeline analysis: shows events in chronological order so the investigator can see what happened and when.
  5. Advanced search: filters data using criteria like keywords, file types or dates.
  6. Reporting: creates detailed reports summarising the evidence.
  7. Integration: works with other forensic tools and databases to support collaboration.

Write 5 of the 7. Remember: "Five Doctors Do Tests And Report Immediately".

Q3. Describe how Wireshark is used in digital forensics. Give THREE uses. [6 marks]

Wireshark is an open-source tool that captures and analyses network packets in real time, with deep packet inspection of hundreds of protocols (TCP, UDP, HTTP, DNS, FTP).

  1. Intrusion detection: identifies unauthorised access attempts or data being sent out of the network (exfiltration).
  2. Malware analysis: tracks the communication patterns of malware, e.g. connections to a command-and-control (C2) server.
  3. User activity monitoring: shows which websites, applications and remote services a user accessed and when.

Its display filters help isolate suspicious traffic, and captures can be exported as evidence.

Q4. What is Volatility? Why is memory (RAM) analysis important? List its features. [8 marks]

Volatility is a forensic tool that analyses volatile memory dumps (copies of RAM) taken from a computer.

Why important: RAM is lost when the computer is turned off. It contains evidence that may not be on the hard disk: running processes, network connections, encryption keys, passwords, and malware that runs only in memory. Capturing and analysing RAM saves this evidence.

Features:

  1. Memory image analysis: analyse dump files manually or automatically.
  2. System information: hardware/software configuration, drivers and services.
  3. Process and thread analysis: track running processes and their behaviour.
  4. File system analysis: data, deleted files and metadata at that point in time.
  5. Registry analysis: installed applications, configuration and user settings.
Q5. State the locations of the SAM and NTUSER.DAT registry hives and what each one contains. [4 marks]
  • SAM: C:\Windows\System32\config\SAM. Holds user account information and password hashes.
  • NTUSER.DAT: C:\Users\<username>\NTUSER.DAT. Holds one user's personal settings and activity (recent files, typed paths/URLs, preferences).

Other hives in System32\config: SYSTEM, SOFTWARE, SECURITY, DEFAULT. UsrClass.dat is in AppData\Local\Microsoft\Windows.

Q7. Differentiate between Browser History Capturer and Browser History Viewer. [4 marks]

Browser History Capturer extracts browsing history from browsers (Chrome, Edge, Firefox, Internet Explorer) on a Windows computer. It is the collection step.

Browser History Viewer displays the history so the investigator can navigate it, showing every website visited with the date and time of each visit. It is the analysis/viewing step.

Together they reveal a user's browsing patterns and behaviour.

Q8. What is a file system? Why must an investigator understand it? [4 marks]

A file system gives the OS a road map to the data on a disk. The type of file system determines how data is stored, where files are located, and what happens when files are deleted.

An investigator must understand both the OS and file system so they can correctly acquire and inspect data, know where to look for deleted or hidden data, and interpret timestamps and metadata correctly.

Q9. Explain the role of CMOS, BIOS/EFI and the bootstrap process. Why must an investigator be careful when booting a suspect's computer? [8 marks]
  • CMOS: stores system configuration and date/time information, kept when the power is off.
  • BIOS/EFI: contains programs that perform input and output at the hardware level.
  • Bootstrap process: stored in ROM; tells the computer how to start and shows the key to press to open the CMOS setup screen.

Careful because: if the suspect's computer boots normally into its own OS, the OS writes to the disk (updates logs, timestamps, temp files), which alters evidence. The investigator should enter CMOS setup and change the boot order to boot from a forensic boot CD/USB, so the disk is accessed without being changed. They should also record the CMOS date/time and compare it to the real time, because a wrong clock affects the timeline.

Q10. With a diagram, explain the components of a hard disk drive. [6 marks]

Draw a circle (platter) with rings (tracks), a pie-slice (sector) and an arm (head), like the picture in the "Disks" section.

  • Platter: round disk coated with magnetic material.
  • Geometry: the internal organisation of the drive (cylinders, heads, sectors).
  • Head: reads and writes data on the platter.
  • Track: a concentric circle on a platter.
  • Cylinder: a column of the same track across all platters.
  • Sector: a section of a track (usually 512 bytes).
Q11. Explain Zone Bit Recording, track density, areal density and head/cylinder skew. [4 marks]
  • ZBR: groups tracks into zones; outer tracks (longer) hold more sectors than inner ones, so disk space is used better.
  • Track density: the space between each track; higher density = more tracks fit.
  • Areal density: number of bits in one square inch of a platter.
  • Head and cylinder skew: offsets the first sector of the next track/cylinder so the head can keep reading without waiting a full rotation, improving performance.

These are handled at the drive's hardware or firmware level.

Q12. What is disk partitioning? Give FOUR reasons to partition a disk. How can partitions affect an investigation? [6 marks]

Disk partitioning is dividing a hard drive into several logical storage units called partitions.

  1. Organization: separate OS, programs and data.
  2. Multiple OSs: install different operating systems (dual boot).
  3. Performance.
  4. Data backup and recovery: data survives if the OS partition fails.

Investigation: suspects may hide data in hidden partitions, deleted partitions or gaps between partitions. The investigator should examine the whole disk including unallocated space. (Open Disk Management with Win+R → diskmgmt.msc.)

Q13. What is Microsoft BitLocker? Name THREE third-party whole disk encryption tools. Explain one challenge encryption creates for investigators. [6 marks]

BitLocker is a full volume encryption feature built into Windows that protects data by encrypting entire drives.

Third-party WDE tools: PGP Full Disk Encryption, Voltage SecureFile, Utimaco SafeGuard Easy, Jetico BestCrypt Volume Encryption, TrueCrypt (any three).

Challenge: without the password or recovery key the data cannot be read. If the computer is shut down, the drive locks again. Investigators should capture RAM (the key may be in memory) or image the drive while it is still unlocked, and search for recovery keys.

Q14. Define the Windows Registry and explain FIVE registry terms. Why is it useful in forensics? [8 marks]

The Registry is a database that stores hardware and software configuration information, network connections, user preferences and setup information. It is viewed with Regedit or Regedt32.

  • HKEY: root-level folder of the registry.
  • Key: a folder in the registry.
  • Subkey: a folder inside a key.
  • Branch: the hierarchical path to a key.
  • Value: the setting data stored in a key.
  • Default value: a key's unnamed value.
  • Hives: the main groups of registry files, e.g. HKEY_LOCAL_MACHINE and HKEY_USERS.

Useful because it records attached hardware (e.g. USB drives), installed software, user activity, network connections and preferences, which can link a suspect to actions on the computer.

Q15. What is a virtual machine? Explain TWO ways VMs help forensic investigators and ONE issue they create. [6 marks]

A virtual machine allows you to create a representation of another computer (a guest OS) on an existing physical computer. It is just a few files on the hard drive; you must allocate space to it, it recognises the physical machine's components, and it is limited by the host OS.

Helps: (1) restore a suspect's drive in a VM to see the system as the suspect used it; (2) run nonstandard software the suspect installed, safely and isolated.

Issue: a suspect may use a VM to attack another system or network and then delete the VM files, hiding the evidence. Investigators must look for VM files and software (VMware, VirtualBox, Hyper-V) on suspect drives.

Part B: Week 8 (Recovering Graphics Files)

Q16. Explain the THREE types of graphics files. [6 marks]
  1. Bitmap/raster: a grid of individual pixels (dots) stored in rows. Quality depends on resolution and colour depth; it becomes blocky (pixelated) when enlarged. E.g. .bmp, .jpg.
  2. Vector: based on mathematical instructions for lines and shapes. Smaller files, and quality stays the same when enlarged. E.g. made in CorelDraw, Adobe Illustrator.
  3. Metafile: a combination of bitmap and vector in one file. When enlarged, the vector part stays sharp but the bitmap part loses quality.
Q17. "All bitmaps are raster images, but not all raster images are bitmaps." Explain this statement. [4 marks]

"Bitmap" historically meant an image where each pixel maps directly to bits, originally 1-bit (black and white only), usually uncompressed (.bmp, .dib). "Raster" is the broader category for any pixel-grid image, supporting many colour depths (1, 8, 24, 32-bit) and compression (lossy JPEG, lossless PNG). So a bitmap is one kind of raster image, while raster also includes JPEG, PNG, GIF, TIFF and others.

Q18. What factors affect the quality of a bitmap/raster image? [3 marks]
  1. Screen resolution: determines the amount of detail shown.
  2. Software / drivers: the graphics software and drivers affect display quality.
  3. Number of colour bits per pixel (colour depth): more bits = more colours.

Q20. Explain the RAW file format. What is its main disadvantage, and what is demosaicing? [5 marks]

RAW is the format on higher-end digital cameras, called a digital negative. The sensor records pixels directly onto the memory card with no processing, so it keeps the best picture quality.

Disadvantage: it is proprietary (each manufacturer has its own format), so not all image viewers can display it.

Demosaicing is the process of converting raw picture data into another format (e.g. JPEG or TIFF).

Q21. What is the Exif format? How can Exif metadata help a forensic investigation? Name TWO tools that can read it. [8 marks]

Exif (Exchangeable Image File) is a format commonly used for digital pictures. It was developed by JEITA as a standard for storing metadata in JPEG and TIF files. The metadata is stored at the beginning of the file.

Helps investigation: metadata tells the investigator the type/model of camera used and the environment in which the picture was taken: date and time, GPS location, camera settings (shutter speed, flash). This can link a photo to a suspect's camera, confirm or break an alibi, and place a person at a location. The metadata can be extracted as evidence.

Tools: Exif Reader, IrfanView, ProDiscover.

Q22. What is a file header? State the JPEG header value and explain how an investigator rebuilds a damaged header. [10 marks]

A file header is the unique value at the start of a file that identifies its type. Each graphics file has its own header.

JPEG header: FF D8 FF E0 00 10. Most JPEGs also contain the string JFIF; a JPEG begins with FFD8 followed by the label JFIF (standard JPEG) or Exif at offset 6.

Rebuilding steps: first try to open the recovered file in an image viewer. If it doesn't display:

  1. Recover more pieces of the file if needed.
  2. Examine the file header in a hex editor.
  3. Compare it with a known good header sample.
  4. Manually insert the correct hexadecimal values.
  5. Test the corrected file by opening it.

Work on a copy, and document the changes and hash values to keep the evidence admissible.

Q23. What is data carving from unallocated space? What is a false positive? [6 marks]

Unallocated space is disk space marked as free; deleted file data often remains there until overwritten. Carving is searching that space for known file signatures (e.g. JPEG FFD8 / "JFIF") and extracting the data into a new file, without relying on the file system.

Steps: (1) plan the examination; (2) search for and recover digital photo evidence, e.g. using ProDiscover to search for and extract JPEG files.

A false positive is a false hit: the search finds the signature but the data is not actually a valid image (the bytes just happen to match). Each hit must be verified.

Q24. Why should an investigator keep several image viewer programs? [3 marks]

Because no single viewer can read every file format. Some formats are nonstandard or proprietary (e.g. RAW, PSD, TGA). Having several viewers ensures every recovered file can be opened. Most GUI forensic tools include viewers for common formats, but the investigator must still analyse, identify and inspect every unknown file on the drive.

Q25. Define steganography. Compare insertion and substitution steganography. [8 marks]

Steganography is an ancient technique of hiding information inside another file (e.g. an image) so that the existence of the message is concealed.

InsertionSubstitution
Adds hidden data into the host fileReplaces bits of the host file with bits of hidden data
Hidden data is not displayed when the file is viewed in its associated programUsually changes the last two least significant bits (LSBs); visual change is invisible to the eye
Found by carefully analysing the file's data structureDetected using steganalysis (steg) tools
File size usually increasesFile size usually stays the same
Example: text hidden in a web page's codeExample: message hidden in pixel LSBs of a BMP
Q26. What clues suggest a suspect used steganography? What do steganalysis tools do? [6 marks]

Clues:

  • Duplicate files with different hash values (look the same but aren't identical).
  • Steganography programs installed on the suspect's drive.
  • Changes in file size, image quality or file extension.

Steganalysis tools are used to detect, decode and record hidden data. They detect variations in the graphic image. However, when steganography is applied correctly, the hidden data cannot be detected in most cases, so investigators should inspect all files.

Q27. How is steganography used to protect copyright? What copyright issues should investigators know? [5 marks]

Steganography protects copyrighted material by inserting digital watermarks into a file, which can prove ownership.

Issues: investigators must be aware of copyright laws; copyright laws for the Internet are not clear; there is no international copyright law; the U.S. Copyright Office (www.copyright.gov) identifies what can and can't be covered under U.S. law.

Part C: Scenario / application questions

Q28. Scenario (EMTS): A contract employee of Exotic Mountain Tour Service is suspected of stealing company photos. You have an image of his USB drive, but some JPEG files will not open. Describe how you would recover the evidence. [10 marks]
  1. Preserve evidence: work on a forensic image (e.g. created with FTK Imager), record the hash of the original and the copy.
  2. Plan the examination: we are looking for JPEG photos belonging to EMTS.
  3. Search the image (including unallocated space) using ProDiscover for JPEG signatures FFD8 and the string "JFIF"/"Exif".
  4. Carve / extract the hits into new files; check each for false positives.
  5. Try opening each file in an image viewer. If it won't open, view it in a hex editor.
  6. Rebuild the header: compare with a good JPEG header and insert the correct values FF D8 FF E0 00 10 4A 46 49 46; test the file again.
  7. Examine Exif metadata (Exif Reader / IrfanView / ProDiscover): camera model, date/time, GPS, to prove the photos are EMTS's.
  8. Check for steganography / watermarks and for files with changed extensions.
  9. Document every step, hash values before/after, and write the report.
Q29. Scenario: You find two image files, "beach.bmp" and "beach_copy.bmp", that look exactly the same, but their MD5 hashes are different. A program called "S-Tools" is also installed. What might this mean and what would you do? [6 marks]

This strongly suggests steganography, most likely substitution (LSB). Two identical-looking files with different hashes, plus a steg program installed, are classic clues. Since the files are the same size but different, bits were probably swapped rather than inserted.

Actions: compare the two files byte-by-byte (hex compare) to find where they differ; run steganalysis tools to detect, decode and record the hidden data; check file size, quality and extension; examine the steg program's settings/history; document all findings.

Q30. Scenario: A company suspects an employee's PC is sending data to an unknown server. The PC is still running. Which tools from Week 7 would you use and why? [8 marks]
  1. Volatility: capture RAM first (it is lost if the PC is shut down) and analyse running processes, network connections and any malware in memory. Encryption keys may also be in RAM.
  2. Wireshark: capture network traffic to see where data is going (destination IP, protocol), detect exfiltration and C2 communication.
  3. FTK Imager: create a forensic image of the disk and verify it with a hash.
  4. Autopsy: analyse the disk image: timeline, recovered deleted files, search for the suspicious program.
  5. Registry analysis (NTUSER.DAT, SOFTWARE, SYSTEM): find auto-run programs, installed software, USB devices.
  6. Browser History Capturer/Viewer: check web activity, e.g. uploads to cloud sites.

Order matters: collect the most volatile evidence (RAM, network) first.

Q31. An investigator receives a file called "notes.txt" that is 2 MB and won't open in Notepad. Explain how she can find out what it really is. [4 marks]

The extension may have been changed to hide the file. She should open it in a hex editor (or forensic tool) and look at the file header. If it starts with FF D8 FF E0 and "JFIF" at offset 6, it is really a JPEG. She can then rename a copy to .jpg and open it in an image viewer. A changed extension is also a clue of possible data hiding, so she should check it for steganography and record it in the report.
